# Мой дневник питания и сна

Статическое приложение. Записи хранятся только в браузере пользователя и не отправляются на сервер.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
Открывайте полученный HTTPS-адрес в Safari: Поделиться → На экран «Домой».

Резервные копии с личными записями нельзя добавлять в этот репозиторий.
